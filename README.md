# Drones Made Easy — Μαθητική Έκδοση

Ανοιχτό εκπαιδευτικό υλικό για τη διδασκαλία των drones (Συστήματα Μη Επανδρωμένων Αεροσκαφών) στη Δευτεροβάθμια Εκπαίδευση.

Δημιουργήθηκε για το μάθημα **Ερευνητική Εργασία στην Τεχνολογία**, Α' Λυκείου.

---

## Τι περιέχει

| Φάκελος | Περιεχόμενο |
|---|---|
| [`book/`](book/) | Το βιβλίο σε 16 κεφάλαια, γραμμένο για μαθητές Λυκείου |
| [`curriculum/`](curriculum/) | Πλάνο 20 δίωρων (10 ανά τετράμηνο), θεωρία + πράξη |
| [`moodle/`](moodle/) | Ερωτήσεις quiz ανά κεφάλαιο, έτοιμες για εισαγωγή στο Moodle |
| [`resources/`](resources/) | Σύνδεσμοι σε προσομοιωτές, λογισμικό, προτεινόμενο εξοπλισμό |

---

## Φιλοσοφία του μαθήματος

Το μάθημα είναι **εμπειρικό**: κάθε δίωρο συνδυάζει θεωρία με πρακτική εξάσκηση, ώστε τόσο οι μαθητές όσο και ο εκπαιδευτικός να αποκτούν πραγματική εμπειρία σταδιακά.

Η προσέγγιση είναι **χαμηλού κόστους**: το μεγαλύτερο μέρος της πτητικής εξάσκησης γίνεται σε δωρεάν προσομοιωτές στο εργαστήριο υπολογιστών, ώστε μία ή δύο συσκευές να επαρκούν για ολόκληρο τμήμα.

Το υλικό είναι **αποκλειστικά πολιτικής χρήσης**: φωτογραφία, χαρτογράφηση, γεωργία ακριβείας, επιθεωρήσεις, έρευνα και διάσωση. Δεν περιλαμβάνει στρατιωτικές εφαρμογές.

## Πώς να το χρησιμοποιήσετε

**Μαθητές:** διαβάστε το βιβλίο απευθείας εδώ στο GitHub — ανοίγει σε κάθε browser, χωρίς λογαριασμό.

**Εκπαιδευτικοί:** μπορείτε ελεύθερα να κάνετε *fork* το repository και να προσαρμόσετε το υλικό στις ανάγκες του σχολείου σας. Προτάσεις και διορθώσεις μέσω *Issues* ή *Pull Requests* είναι ευπρόσδεκτες.
