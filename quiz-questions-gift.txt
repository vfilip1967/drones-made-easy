$CATEGORY: Drones/Κεφ01 Εισαγωγή

::K1Q1:: Ποια υπηρεσία είναι υπεύθυνη για την καταγραφή drones στην Ελλάδα; {
=Υπηρεσία Πολιτικής Αεροπορίας (ΥΠΑ)
~Υπουργείο Παιδείας
~Ελληνική Αστυνομία
~Εθνική Μετεωρολογική Υπηρεσία
}

::K1Q2:: Από ποιο βάρος και πάνω απαιτείται καταγραφή drone; {
=250 γραμμάρια
~100 γραμμάρια
~1 κιλό
~5 κιλά
}

::K1Q3:: Η γεωργία ακριβείας είναι επαγγελματική εφαρμογή των drones. {TRUE}

$CATEGORY: Drones/Κεφ02-03 Τύποι

::K3Q1:: Ποιος τύπος drone είναι καταλληλότερος για χαρτογράφηση μεγάλης έκτασης; {
=Fixed-wing (τύπου αεροπλάνου)
~Τετρακόπτερο
~Ελικόπτερο
~FPV racing drone
}

::K3Q2:: Το VTOL συνδυάζει κάθετη απογείωση με οριζόντια πτήση αεροπλάνου. {TRUE}

::K3Q3:: Ένα drone κατάλληλο για αρχάριους σε εσωτερικό χώρο πρέπει να έχει {=prop guards (προστατευτικά ελίκων)}.

$CATEGORY: Drones/Κεφ04 Μέρη

::K4Q1:: Ποιο εξάρτημα λειτουργεί ως «εγκέφαλος» του drone; {
=Flight Controller (FC)
~ESC
~Δέκτης
~Μπαταρία
}

::K4Q2:: Τι κάνει το ESC; {
=Ρυθμίζει την ταχύτητα περιστροφής των κινητήρων
~Λαμβάνει σήμα από το χειριστήριο
~Μετρά το ύψος πτήσης
~Αποθηκεύει το βίντεο
}

::K4Q3:: Ο αισθητήρας που μετρά τον προσανατολισμό του drone ονομάζεται {=IMU} ή γυροσκόπιο.

$CATEGORY: Drones/Κεφ05 Μπαταρίες

::K5Q1:: Τι σημαίνει «4S» σε μια μπαταρία LiPo; {
=4 cells σε σειρά, περίπου 14.8V
~4 ώρες αυτονομία
~4 amp κατανάλωση
~4 φορές επαναφορτιζόμενη
}

::K5Q2:: Επιτρέπεται η φόρτιση μπαταρίας LiPo χωρίς επίβλεψη. {FALSE}

::K5Q3:: Η ειδική πυρίμαχη θήκη φύλαξης μπαταριών ονομάζεται {=LiPo bag}.

$CATEGORY: Drones/Κεφ06 Αεροδυναμική

::K6Q1:: Ποιος άξονας ελέγχου ανεβάζει και κατεβάζει το drone; {
=Throttle
~Pitch
~Roll
~Yaw
}

::K6Q2:: Ο άξονας που περιστρέφει το drone γύρω από τον εαυτό του ονομάζεται {=Yaw}.

::K6Q3:: Ένα πολυκόπτερο κινείται μπροστά γέρνοντας, όχι με πτερύγια. {TRUE}

$CATEGORY: Drones/Κεφ07 Μετεωρολογία

::K7Q1:: Τι σημαίνει VLOS; {
=Visual Line Of Sight — οπτική επαφή με το drone
~Very Low Orbit System
~Vertical Landing Operation Standard
~Variable Light Optical Sensor
}

::K7Q2:: Επιτρέπεται πτήση drone υπό βροχή. {FALSE}

$CATEGORY: Drones/Κεφ08 Πομποδέκτες

::K8Q1:: Ποια είναι σύγχρονα πρωτόκολλα ελέγχου FPV; {
=ExpressLRS και Crossfire
~Bluetooth και NFC
~WiFi 6 και 5G
~USB και HDMI
}

::K8Q2:: Το bind «πέτυχε» αλλά το drone δεν αντιδρά. Τι ελέγχουμε πρώτα; {
=Αν πομπός και δέκτης χρησιμοποιούν το ίδιο πρωτόκολλο
~Αν η κάμερα λειτουργεί
~Αν οι έλικες είναι καθαρές
~Αν υπάρχει κάρτα μνήμης
}

::K8Q3:: Στο Betaflight Configurator, το tab όπου βλέπουμε αν κινούνται τα κανάλια είναι το {=Receiver}.

$CATEGORY: Drones/Κεφ09-11 Λογισμικό και πτήση

::K9Q1:: Ποιο λογισμικό χρησιμοποιείται για αυτόνομη αποστολή με waypoints; {
=Mission Planner
~Betaflight Configurator
~Microsoft Word
~Photoshop
}

::K11Q1:: Σύμφωνα με τον κανόνα ασφαλείας, προσγειώνουμε πριν η μπαταρία πέσει κάτω από {=50}%.

$CATEGORY: Drones/Κεφ10 Οργάνωση

::K10Q1:: Ποιος ρόλος πληρώματος παρακολουθεί το περιβάλλον για κινδύνους; {
=Spotter
~Pilot
~Καταγραφέας
~Τεχνικός
}

::K10Q2:: Ο προπτητικός έλεγχος (checklist) γίνεται μόνο στην πρώτη πτήση της ημέρας. {FALSE}

$CATEGORY: Drones/Κεφ12 Προγραμματισμός

::K12Q1:: Ποια εντολή της djitellopy σηκώνει το drone στον αέρα; {
=takeoff()
~fly()
~start()
~up()
}

::K12Q2:: Η βιβλιοθήκη Python για τον έλεγχο του DJI Tello ονομάζεται {=djitellopy}.

$CATEGORY: Drones/Κεφ13 Επαγγελματική χρήση

::K13Q1:: Ποιος ευρωπαϊκός οργανισμός ρυθμίζει τους κανόνες πτήσης drone; {
=EASA
~NASA
~UNESCO
~NATO
}

::K13Q2:: Η ασφάλιση αστικής ευθύνης είναι απαραίτητη για επαγγελματική χρήση drone. {TRUE}

$CATEGORY: Drones/Κεφ15 Ηθική

::K15Q1:: Σε ποια από τις παρακάτω περιοχές απαγορεύεται η πτήση drone; {
=Κοντά σε αεροδρόμιο
~Σε πάρκο εκτός ωραρίου αιχμής
~Στην αυλή του σχολείου με άδεια
~Σε ανοιχτό χωράφι
}

::K15Q2:: Η φωτογράφιση ιδιωτικού χώρου τρίτου χωρίς άδεια μπορεί να αποτελεί παραβίαση προσωπικών δεδομένων. {TRUE}

$CATEGORY: Drones/Κεφ16 Μέλλον

::K16Q1:: Ποια τεχνολογία επιτρέπει σε σύγχρονα drones να αποφεύγουν εμπόδια αυτόνομα; {
=Αισθητήρες με επεξεργασία AI
~Ραδιόφωνο FM
~Ηλιακοί συλλέκτες
~Δορυφορικό τηλέφωνο
}

::K16Q2:: Οι πολυφασματικές κάμερες χρησιμοποιούνται στη γεωργία ακριβείας για τον εντοπισμό προβλημάτων σε καλλιέργειες. {TRUE}
